一键部署

触发 GitHub Actions 重新部署当前仓库版本。

网站文案设置

这里保存的是常用文案。保存后前台会自动读取，不需要改 HTML。

导入笔记 / 项目

可以导入或编辑标题、说明和链接。长期连载笔记建议保持同一个 PDF 路径不变，更新时替换同名文件并重新部署。

友链管理

管理友链跳转、头像和简介。头像可以填完整图片链接，也可以填站内路径，例如 assets/avatar.jpg。

说说发布

像发动态一样写一条短记录。图片和背景图先填写链接或站内 assets 路径；等后续接入存储后可以换成上传。

音乐管理

这里管理首页播放器和独立音乐页共用的歌单。音频与封面可以填写站内路径，例如 assets/music/song.mp3，也可以填写外链。

批量导入歌单

可粘贴 JSON 数组，字段支持 title、artist、src、cover、lyrics、note、source、sourceId。也支持一行一首：标题 | 作者 | 音频路径 | 封面路径 | 歌词 | 备注 | 来源 | 来源ID。

从网易云歌单 / 单曲导入

填写公开歌单、单曲链接或 ID。这里主要导入标题、作者、封面、歌词和歌曲 ID；音频 mp3 仍建议你之后自己上传并填写站内路径。

提问箱管理

访客提问默认不会公开。登录用户的提问可以回复为“只显示给提问者”，所有提问都可以选择“公开展示”。

评论区管理

这里之后会管理讨论区评论。目前可以查看和删除已经保存的评论。
